# SOTA Reference Library

Papers we benchmark against. Numbers in `benchmarks.md` are paper-reported and never blended into our experimental results.

## Downloaded
- **khan2024_x_lstm_eo.pdf** — Khan et al. — Explainable AI and optimized solar power generation forecasting (X-LSTM-EO)  
  Dataset: anikannal Solar Power Generation Data (Plant 1)  
  Reported: MAE = 0.229 (normalized)  
  Tag: _PRIMARY SOTA TARGET_  
  Landing: <https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0308002>
- **solar_ml_comparison_plos.pdf** — Solar energy prediction through ML: comparative regressor analysis  
  Dataset: anikannal Solar Power Generation Data  
  Reported: see paper Table  
  Tag: _Same-dataset baselines_  
  Landing: <https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0315955>
- **stacking_metamodel_altitude.pdf** — Optimizing photovoltaic power prediction at extreme altitudes using stacking metamodels and dimensionality reduction  
  Dataset: Bolivia high-altitude PV plant  
  Reported: MAE = 6.76 (kW), R^2 = 0.9999  
  Tag: _Stacking blueprint_  
  Landing: <https://www.nature.com/articles/s41598-025-22185-x>
- **ultra_short_term_2509_17095.pdf** — Ultra-short-term solar power forecasting by deep learning and data decomposition  
  Dataset: Multiple PV plants  
  Reported: see paper  
  Tag: _Recent open-access reference_  
  Landing: <https://arxiv.org/abs/2509.17095>
- **france_renewables_benchmark.pdf** — Towards Accurate Forecasting of Renewable Energy: France benchmarking  
  Dataset: France solar + wind, 2012-2023 hourly  
  Reported: see paper  
  Tag: _Benchmarking framework_  
  Landing: <https://arxiv.org/abs/2504.16100>
- **ensemble_postprocessing_pv.pdf** — Post-processing of ensemble photovoltaic power forecasts with distributional and quantile regression methods  
  Dataset: Operational PV forecasts  
  Reported: see paper  
  Tag: _Post-processing reference_  
  Landing: <https://arxiv.org/abs/2508.15508>
- **quantum_ml_pv_forecast.pdf** — Photovoltaic power forecasting using quantum machine learning  
  Dataset: PV plant  
  Reported: see paper  
  Tag: _Alternative model class_  
  Landing: <https://arxiv.org/abs/2312.16379>
